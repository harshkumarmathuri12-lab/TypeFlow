# TypeFlow

TypeFlow is a clean and responsive typing speed test website inspired by Monkeytype. It helps users practice typing while measuring WPM (Words Per Minute), accuracy, and typing performance in real time.

## Features
- Real-time WPM & Accuracy
- Multiple timer modes (15s, 30s, 60s, 120s)
- Live character highlighting
- Responsive dark UI
- Results screen with typing statistics
- Built with HTML, CSS & JavaScript

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
